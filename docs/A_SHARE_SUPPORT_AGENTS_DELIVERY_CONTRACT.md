# 三个辅 Agent 早 / 晚交付合同（宏观 / 商品 / AI科技）（Phase 1 / v1）

## 1. 文档目的

这份文档定义三个辅 Agent 的 Phase 1 交付合同。

本阶段辅 Agent 的目标不是独立抢主线，而是：

- 为主 Agent 提供专业 support evidence
- 帮助主 Agent 做验证、修正、降噪
- 在各自域内给出最重要、最可执行、最不重复的支持判断

本阶段先定义：

- 早报 support 合同
- 晚报 support 合同

盘中合同暂由主 Agent 为主消费高频变化，辅 Agent 盘中深度自动化属于后续阶段。

---

## 2. 三个辅 Agent 的共同规则

### 2.1 共同职责

每个辅 Agent 都必须做到：

1. 只回答自己视角内最重要的问题
2. 输出对主 Agent 真正有用的 support judgment
3. 明确指出“支持 / 修正 / 反证”哪一种关系
4. 尽量压缩为少数高价值结论，而不是大段铺陈

### 2.2 共同禁止事项

- 不得重写一遍主市场综述
- 不得把所有观察都写进去
- 不得替代主 Agent 做最终市场总判断
- 不得在证据不足时给出过满判断

### 2.3 标准输出形态

每个 support output 建议统一为四段：

- **Support conclusion**
- **Why it matters to A-share today**
- **Key evidence**
- **Invalidation / caution**

---

## 3. 宏观辅 Agent 合同

## 3.1 宏观辅 Agent 的职责

宏观辅 Agent 只负责判断：

- 今天宏观背景对 A 股是顺风、逆风还是中性
- 哪些政策 / 利率 / 汇率 / 流动性变化值得进入主报告
- 哪些宏观信息只是背景，不应被当成交易主驱动

## 3.2 早报必须交付

### 必交问题
- 开盘前宏观背景是否支持风险偏好
- 是否有必须纳入主报告的宏观变化
- 今天宏观层最大的误判风险是什么

### 建议章节
- 今日宏观结论
- 对 A 股主线的支持/压制关系
- 最重要证据 1-3 条
- 风险或不确定性

## 3.3 晚报必须交付

### 必交问题
- 今天宏观背景在市场表现中是否真正起作用
- 它更像驱动、放大器，还是背景噪音
- 哪些宏观变量需要进入次日观察

### 不应重复
- 不重写日内市场涨跌复盘
- 不把所有海外消息都罗列

---

## 4. 商品辅 Agent 合同

## 4.1 商品辅 Agent 的职责

商品辅 Agent 只负责判断：

- 商品价格和结构变化，对 A 股哪些链条有解释力
- 哪些资源 / 周期 / 上下游映射值得进入主报告
- 哪些商品波动只是背景波动，不能直接上升为 A 股主线解释

## 4.2 早报必须交付

### 必交问题
- 今天有哪些商品/资产链条值得预先关注
- 它们可能支撑或压制哪些 A 股方向
- 哪些映射关系今天最值得验证

### 建议章节
- 今日商品 support 结论
- 关联 A 股方向
- 最重要证据 1-3 条
- 失效条件

## 4.3 晚报必须交付

### 必交问题
- 今天商品链条变化是否真的解释了 A 股相关方向
- 哪些关联成立，哪些只是表面同步
- 次日是否仍值得追踪

### 不应重复
- 不独立做完整商品市场日报
- 不对无可靠映射的波动强做股票解释

---

## 5. AI科技辅 Agent 合同

## 5.1 AI科技辅 Agent 的职责

AI科技辅 Agent 只负责判断：

- AI / 科技方向内哪些细分主线在强化或退潮
- 哪些龙头 / 跟随 / 扩散链条值得进入主报告
- AI科技是否应提升为当日主线、次主线，或继续观察

## 5.2 早报必须交付

### 必交问题
- 盘前 AI科技方向是否具备主线候选资格
- 哪些细分值得重点盯
- 哪些只是旧热点残留或题材噪音

### 建议章节
- 今日 AI科技结论
- 重点细分方向
- 核心跟踪对象
- 风险与失效条件

## 5.3 晚报必须交付

### 必交问题
- AI科技今天是主线、支线还是噪音
- 扩散链条是否真实成立
- 次日还应不应该保留高优先级

### 不应重复
- 不把整个 A 股科技股当成独立总报告再写一遍
- 不仅凭个别热门票就推导整个科技主线

---

## 6. 三个辅 Agent 的“不重复矩阵”

## 6.1 宏观辅 Agent 不应重复
- 个股情绪结构复盘
- 板块内部龙头梯队拆解
- AI主题内部竞争格局细节

## 6.2 商品辅 Agent 不应重复
- 泛市场风格判断
- 宏观政策总论
- 科技题材演绎分析

## 6.3 AI科技辅 Agent 不应重复
- 总体流动性/政策判断
- 全市场周期/商品链解读
- 与 AI科技无关的大盘泛化叙述

---

## 7. Support 输出如何被主 Agent 消费

主 Agent 消费 support 时，只需接三类关系：

- **support**：强化主判断
- **adjust**：要求主判断修正力度或优先级
- **counter**：对主判断形成反证或风险提示

因此 support Agent 的交付目标不是“完整”，而是“可被主 Agent 直接装配”。

---

## 8. Phase 1 范围说明

本阶段 support Agent 明确包含：

- 盘前 support note
- 收盘后 support note
- 与主 Agent 的结构化引用关系

本阶段明确后置：

- 高成熟度盘中自动更新 support stream
- 跨客户风格化 support 模板
- US 镜像 support 体系
- support-quality 自动评分
