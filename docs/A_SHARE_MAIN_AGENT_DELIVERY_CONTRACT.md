# A股主 Agent 早 / 中 / 晚交付合同（Phase 1 / v1）

## 1. 文档目的

这份文档只定义 A股主 Agent 的交付合同。

核心问题：

- 每个时段主 Agent 必须交什么
- 什么叫交付完成
- 交付中允许依赖哪些 support inputs
- 哪些内容不该由主 Agent 重复承担

---

## 2. 主 Agent 的统一职责

主 Agent 在所有时段都必须承担四个统一职责：

1. **主判断形成**：给出当天 A 股最重要的主线判断
2. **优先级排序**：明确最值得看的方向 / 变量 / 风险
3. **support 整合**：选择性吸收宏观 / 商品 / AI科技的支持证据
4. **执行语言输出**：把判断翻成可读、可跟踪、可复盘的业务语言

统一禁止事项：

- 不把 support section 原样复制进主报告
- 不做脱离证据的情绪化判断
- 不把“事实堆砌”误当成主线结论

---

## 3. 早报合同（盘前）

## 3.1 目标

在开盘前，建立一个可被验证的主线预案。

## 3.2 必须回答的业务问题

1. 今天 A 股最值得优先观察的主线是什么
2. 这条主线的支持证据是什么
3. 开盘后什么现象会验证它
4. 什么现象会推翻或削弱它
5. 今日不该误判成主线的噪音有哪些

## 3.3 必交内容

早报至少包含以下章节：

### A. 今日主结论
- 一句话主判断
- 主判断方向标签（如强化 / 延续 / 分歧 / 切换预警）

### B. 今日关键观察清单
- 重点主题 / 板块 / 风格
- 重点标的池（来自 key_focus / focus）
- 需要优先验证的事件或价格行为

### C. Support 摘要
- 宏观是否支持风险偏好或压制风险偏好
- 商品是否对资源 / 周期 / 相关链条形成支持或拖累
- AI科技方向是否具备提升为主线的条件

### D. 风险与失效条件
- 哪些开盘现象会让当前预案失效
- 哪些风险属于高优先级跟踪项

### E. 开盘验证计划
- 开盘后 1 个最关键验证点
- 09:27 / 09:29 之后最应观察的变化

## 3.4 早报的完成标准

满足以下条件才算完成：

- 有明确主线，而不是泛泛罗列热点
- 有验证条件，而不是只给观点
- 有风险条件，而不是只给乐观叙事
- support evidence 已被压缩为对主判断真正有用的部分

## 3.5 早报不应做什么

- 不应写成长篇宏观综述
- 不应把商品和AI科技写成各自独立日报
- 不应对收盘后才成立的事实做强结论

---

## 4. 中报合同（盘中）

## 4.1 目标

检查盘前预案是否成立，并做必要修正。

## 4.2 必须回答的业务问题

1. 盘前主线是否被验证
2. 当前主线是在强化、扩散、分歧还是转弱
3. 是否出现新的替代主线
4. 午后最该继续追踪什么

## 4.3 必交内容

### A. 盘中主结论
- 当前主线状态
- 相比早盘的变化结论

### B. 关键验证结果
- 早盘关键验证点是否成立
- 哪些信号超预期 / 不及预期

### C. 盘中结构更新
- 领涨 / 跟涨 / 掉队 / 分化情况
- 是否出现由点到面扩散
- 是否出现高低切换、主线切换或情绪衰减

### D. Support 修正摘要
- 宏观背景是否仍有效
- 商品相关映射是否增强或失效
- AI科技链条是否升格、降级或保持观察

### E. 午后行动框架
- 午后最值得继续验证的 1-3 个点
- 当前最主要风险

## 4.4 中报完成标准

- 明确说明“盘前预案是否成立”
- 明确说明“当前有没有结构性变化”
- 明确说明“午后还看什么”

## 4.5 中报不应做什么

- 不能变成实时流水账
- 不能机械重复早报结论
- 不能在高频证据不足时强做 intraday 细结论

---

## 5. 晚报合同（收盘后）

## 5.1 目标

形成可复盘的日终主判断，并为次日准备输入。

## 5.2 必须回答的业务问题

1. 今天主线最终是否成立
2. 主线强弱、扩散、分歧的核心原因是什么
3. 哪些证据最能解释今天市场
4. 明天延续观察点是什么

## 5.3 必交内容

### A. 日终主结论
- 今日最重要主线
- 今日市场结构结论

### B. 主线归因
- 为什么强 / 为什么弱 / 为什么分化
- 哪个证据最关键

### C. 结构拆解
- 主要方向与次级方向的表现关系
- 龙头 / 跟风 / 失败方向的区分
- 是否存在风格切换或风险偏好变化

### D. Support 整合结论
- 哪些宏观因素今天真正重要
- 哪些商品变化今天真正有解释力
- AI科技今天是主线、分支还是噪音

### E. 次日准备
- 次日首要观察项
- 已确认机会
- 未确认风险

## 5.4 晚报完成标准

- 对当天主线给出明确结论
- 有清楚归因，不只是复述涨跌
- 能沉淀为次日早报的输入
- 能对接 FSJ 结构与章节证据映射

## 5.5 晚报不应做什么

- 不把所有行业都平铺成同权叙述
- 不以“市场震荡”这种空话替代判断
- 不在 daily-final 事实不足时装作结论完整

---

## 6. 主 Agent 与 support 的边界

主 Agent 可以引用 support，但应遵守：

- **只吸收与主判断直接相关的 support 结论**
- 以“支持 / 修正 / 反证”三种关系引用 support
- 不复制 support Agent 的原始长段落

建议主 Agent 汇总时统一采用：

- support_macro
- support_commodities
- support_ai_tech

三个逻辑标签，而不是全文粘贴。

---

## 7. 与数据现实的对齐说明

Phase 1 主 Agent 的可靠性边界必须与当前数据现实一致：

- 盘前 / 盘中更依赖 highfreq working 与低频补充，结论必须允许降级
- 晚报更依赖 midfreq daily-final 与 T-1 archive_v2，上限更高、稳定性更强
- 当 collector freshness 不足时，主 Agent 必须降低结论力度，而不是假装完整
